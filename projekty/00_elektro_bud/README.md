# Projekt Elektro-Bud – analiza wymagań

Projekt przedstawia analizę wymagań dla systemu zarządzania magazynem firmy Elektro-Bud.

## Zawartość projektu

- wymagania funkcjonalne,
- wymagania niefunkcjonalne,
- aktorzy systemu,
- przypadki użycia,
- diagram UML Use Case,
- relacje `<<include>>` i `<<extend>>`.

## Pliki

- `README.md` – opis projektu,
- `analiza_wymagan.md` – pełna analiza wymagań,
- `diagram_use_case.puml` – diagram przypadków użycia UML.

## Cel systemu

System ma usprawnić zarządzanie magazynem firmy Elektro-Bud oraz zastąpić część obecnych papierowych i ręcznych sposobów ewidencji.

System umożliwia między innymi wyszukiwanie produktów, sprawdzanie stanów magazynowych, przyjmowanie i wydawanie towarów, prowadzenie historii operacji oraz zarządzanie użytkownikami.
